Now lets create a pipeline in Jenkins
-------------------------------------

Get code from GitHub --> as Dockerfile exits in the repo, we can build using pipeline
-- https://github.com/sugganabalaji/dockerproject

But we don't have only 1 image, we need to create multiple images like internetbanking, Mobilebanking, loan and insurance
For this, lets have image as a variable not a direct entry in pipeline as docker build -t internetbanking:v1 , instead use docker build -t $image

create image as a parameter

In Pipeline select : This project is parameterized --> Add Parameter --> choice parameter
Name:  image
choices :
    internetbanking:v1
    mobilebanking:v1
    insurance:v1
    loans:v1

Name:  repo
choices :
    sugganabalaji/ib-image
    sugganabalaji/mb-image
    sugganabalaji/insurance
    sugganabalaji/loans

Manage Jenkins > System > Environmental Variables
    Add >
        Name: Password
        Value: Balubava@2018
save

pipeline {
    agent any

    stages {
        stage('checkout') {
            steps {
                git 'https://github.com/sugganabalaji/dockerproject.git'
            }
        }
        stage('build') {
            steps {
                sh 'docker build -t $image .'
            }
        }
        stage('Tagging') {
            steps {
                sh 'docker tag $image $repo'
            }
        }
        stage('Login&Push') {
            steps {
                sh 'docker login -u sugganabalaji -p $password'
                sh 'docker push $repo'
            }
        }
        stage('Deploy') {
            steps {
                sh 'docker stack deploy -c docker-compose.yml my-app'
            }
        }
     }
}


Save

=== Now Deployment ===

Let's use docker swarm to have HA , for this we need containers, lets use docker-compose
And docker compose is used to create multiple containers but in single host, but we need containers in all hosts(workernodes)
Lets use docker stack

show docker-compose.yml in GitHub

version: '3.8'
services:
  internetbanking:
    image: sugganabalaji/ib-image:latest
    ports:
      - "81:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/internetbanking
  mobilebanking:
    image: sugganabalaji/mb-image:latest
    ports:
      - "82:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/mobilebanking
  insurance:
    image: sugganabalaji/insurance-image:latest
    ports:
      - "83:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/insurance
  loan:
    image: sugganabalaji/loans-image:latest
    ports:
      - "84:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/loan



And add this below to pipeline , and bank is application name

    stage('Deploy') {
        steps {
            sh 'docker stack deploy -c docker-compose.yml bank'
        }
    }
